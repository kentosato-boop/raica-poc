# 用語集

作成日: 2026-07-26 ／ 目的: 初めて見る人が本パッケージと `docs/` を読むための最小の語彙

| 用語 | 意味 |
|---|---|
| **RAiCA** | 本プロダクト。人材紹介の「今日誰に何をするか」に特化した業務アプリ（v1.1.0-fullstack）。 |
| **RA** | Recruiting Advisor＝**企業担当**。求人を受け、候補者を推薦し、書類・面接の催促を回す。 |
| **CA** | Career Advisor＝**候補者担当**。候補者の意向確認・面接後フォロー・クロージングを回す。 |
| **成約** | 「**企業OK ∧ 人材OK**」が揃った状態。RA/CA 両画面が対になっているのはこのため。 |
| **Porters** | 既存の人材データベース（正本＝記録系 SoR）。RAiCA はここのデータを同期して使う。 |
| **SoR / SoA** | System of Record（記録系＝Porters）／ System of Action（行動系＝RAiCA）。役割分担の軸。 |
| **HITL** | Human-in-the-loop。AI は下書きまで、**送信・判断は必ず人間が承認**する運用。 |
| **9軸スコアリング** | スキル/総経験/日本語/給与/通勤/年齢/勤務形態/専門経験/職歴安定性 の重み付き合成スコア。判断の主役ではなく参考値。 |
| **要件ずらし** | 機械適用なら落ちる候補を、前例を根拠に条件緩和して提案すること（判断は人間）。 |
| **成約類似** | この企業が過去に採用した人との経歴パターン類似度（%）。マッチング根拠の第一優先。 |
| **NG照合** | この企業の不成約・辞退パターンに該当しないかの確認。 |
| **ルールエンジン** | RA=推薦後3営業日/CA=接触後2営業日 の連絡ルールで対応キューを生成する仕組み。 |
| **学習値** | 企業別「平均返答日数」・候補者別「平均反応日数」。ルールより優先して前倒し警告を出す。 |
| **休眠掘り起こし** | 最終接触1年超の休眠候補者（19,842件・想定）へ AI 文面で再接触する施策。 |
| **予兆検知** | 企業の再募集の兆し（求人サイト掲載・報道・定期メール返信）を検知する仕組み。 |
| **Outbox** | 外部送信の再送キュー。連携先が障害でも送信指示を失わない設計。 |
| **Zalo OA** | ベトナムのメッセージ基盤（Official Account）。候補者向け個別配信に使用（フォロワーのみ）。 |
| **Asana** | タスク管理。RAiCA と双方向同期し、AI 提案タスクを自動起票。置き換えでなく補完。 |
| **PDPL / 政令13号** | ベトナムの個人データ保護法・関連政令。匿名化・国内保管・同意・オプトアウトの根拠。 |
| **ZDR** | Zero Data Retention。LLM に学習利用させない設定＋証跡保管。 |
| **PoC** | Proof of Concept＝概念実証。2ヶ月の成功条件で効果を実測するフェーズ。 |
| **想定値 / 実測** | 想定値＝仕様に基づくモック（🟡）。実測＝PoC で測った実データ（🟢）。混同しない（`02` 参照）。 |
| **【要確認】** | リポジトリに一次情報がなく、案件責任者が事実で埋める欄。推測で埋めていない。 |
