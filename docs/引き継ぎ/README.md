# 東京博善案件 引き継ぎ・連携パッケージ（勝さん・畑澤さん向け）

作成日: 2026-07-26

このフォルダは、本案件（東京博善案件＝人材紹介ツール RAiCA の PoC）を**初めて見る勝さん・畑澤さんが、聞かなくても現状を把握し、連携して動き出せる**ように整えた資料一式です。

> **重要な前提**（詳細は `00` §0）
> - 一次情報源は `raica-poc` リポジトリ。記述はすべて出所付き。
> - 東京博善との座組など外部固有情報は `【要確認】` として空欄化（推測で埋めていない）。
> - 作成にあたり**関係者へ一切連絡していません**（送信ゼロ）。共有の判断は人が行ってください。
